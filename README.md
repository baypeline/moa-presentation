# Moa HTML Presentation

12페이지로 구성된 오프라인 발표 자료.

## 실행

`index.html`을 Chrome 또는 Edge에서 열기.

첫 화면의 `전체 화면으로 시작`을 클릭하면 브라우저 UI를 숨긴 발표 모드로 전환.

브라우저가 로컬 영상 재생을 제한할 경우 이 폴더에서 간단한 로컬 서버 실행 권장.

```powershell
python -m http.server 4173
```

이후 `http://localhost:4173` 접속.

## 영상 교체

다음 이름으로 MP4 파일 배치.

- `assets/happy-path.mp4`
- `assets/attack-path.mp4`

## 조작

- 화면 왼쪽 클릭: 다음 요소와 다음 페이지
- 화면 오른쪽 클릭: 이전 요소와 이전 페이지
- 영상 영역 클릭: 영상 재생 또는 일시정지
- `→` 또는 `Space`: 다음 요소와 다음 페이지
- `←`: 이전 요소와 이전 페이지
- `Enter`: 영상 재생 또는 일시정지
- `F`: 전체 화면
- `R`: 현재 페이지 처음부터 재생
- `N`: 발표자 노트
- `H`: 도움말
